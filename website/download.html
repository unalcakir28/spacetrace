What “continuous” means

Until the first tagged release, every download here is the newest build of main: it has passed CI and nothing else. When a stable release exists this page switches to it automatically and the version above stops saying “latest build”.

CLI and agent

One archive holds both binaries: spacetrace for the command line and spacetrace-agent for the service that scans on a schedule and answers over HTTP. Apache-2.0.

Linux builds are static musl, so they run on old glibc and inside a scratch container. Every archive also holds the README and the licence.

Installing

  1. Run the installer, or unpack it yourself

    The script picks the right archive, unpacks it and copies both binaries into /usr/local/bin. It uses sudo only when that directory is not already writable, and it does not enable services or write config behind your back.

    curl -fsSL https://raw.githubusercontent.com/unalcakir28/spacetrace/main/install.sh | sh

    Somewhere else instead: SPACETRACE_BIN_DIR=~/.local/bin. A specific version: SPACETRACE_VERSION=v0.1.0. By hand:

    tar -xzf spacetrace-*.tar.gz && sudo install -m755 spacetrace spacetrace-agent /usr/local/bin/

  2. Check it runs

    spacetrace scan ~/Downloads

    On macOS, scanning outside your home folder needs Full Disk Access for your terminal: System Settings → Privacy & Security → Full Disk Access. Without it the scan still finishes and reports the paths it could not read.

  3. Windows

    Unzip it and put spacetrace.exe somewhere on your PATH. There is no installer for the CLI, and nothing is written outside the folder you unpack into and the snapshot database.

Nothing here is code-signed

Signing certificates cost money per year and cannot live in a public repository, so macOS and Windows will both stop you the first time. This is worth being suspicious about, which is why the checksums are published beside every file and the source of the build is a workflow you can read.

  1. macOS: “spacetrace can’t be opened”

    Open the .dmg, drag the app to Applications, then right-click it and choose Open — that gives the one-time permission a double-click does not offer. Or clear the quarantine flag directly:

    xattr -dr com.apple.quarantine /Applications/spacetrace.app

    Scanning outside your home folder needs Full Disk Access for the app, in System Settings → Privacy & Security.

  2. Windows: SmartScreen

    “Windows protected your PC” → More info → Run anyway. The installer is per-user and needs no administrator rights.

  3. Linux

    sudo apt install ./spacetrace-desktop-*-linux-x86_64.deb

    The AppImage needs no install at all: chmod +x spacetrace-*.AppImage && ./spacetrace-*.AppImage. On Wayland, if the window comes up blank, run it with WEBKIT_DISABLE_DMABUF_RENDERER=1 — a WebKitGTK issue rather than an app one.

docker pull ghcr.io/unalcakir28/spacetrace-hub:main

Check what you downloaded

Every release carries a SHA256SUMS file covering its own assets. Verify before you install, especially since none of the binaries are signed. 

# in the folder you downloaded into
curl -LO https://github.com/unalcakir28/spacetrace/releases/download/continuous/SHA256SUMS
sha256sum -c --ignore-missing SHA256SUMS

macOS has no sha256sum; use shasum -a 256 -c instead.

Or build it yourself

The core, the CLI and the agent are Apache-2.0 and need only Rust 1.85 or newer. 

git clone https://github.com/unalcakir28/spacetrace
cd spacetrace
cargo build --release
# the binaries land in target/release/
./target/release/spacetrace --help

cargo install --path crates/cli puts spacetrace on your PATH. The desktop app and the hub are not open source, so they cannot be built from source — that is the trade for the core staying permissively licensed.
